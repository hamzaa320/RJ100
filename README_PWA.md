# RJ100 Toolkit — نسخة الآيفون (PWA — تطبيق من الشاشة الرئيسية)

هذه الحزمة تحل مشكلة آيفون نهائياً: **بدلاً من فتح الملف في قارئ HTML**
(الذي قد لا يشغّل JavaScript)، يصبح الموقع **تطبيقاً يُثبَّت على الشاشة
الرئيسية** ويعمل **بالكامل دون إنترنت** بعد أول فتح.

## لماذا هذا هو الحل؟
- الآيفون لا يسمح بفتح ملفات HTML المحلية بالجافاسكربت إلا عبر متصفح
  ويب كامل، ومعاينة "الملفات" لا تشغّل الجافاسكربت إطلاقاً.
- نسخة PWA تُستضاف على **GitHub Pages (مجاني + HTTPS)**، وفيه يسمح Safari
  بإضافة الصفحة للشاشة الرئيسية كتطبيق مستقل ملء الشاشة.
- ملف `sw.js` يخزّن كل شيء في ذاكرة الجهاز: بعد أول فتح يعمل التطبيق
  تماماً في وضع الطيران (بدون أي إنترنت).

## خطوات النشر (مرة واحدة — تحتاج حساب GitHub مجاني)
1. ادخل إلى https://github.com وافتح حساباً (إن لم يكن لديك).
2. أنشئ **Repository جديد** باسم أي شيء (مثلاً `rj100`)، اتركه Public.
3. ارفع **كل ملفات مجلد `RJ100_PWA`** إلى المجلد الرئيسي للمستودع
   (زر **Add file → Upload files**، اسحب الملفات الستة كلها معاً).
4. من إعدادات المستودع: **Settings → Pages** ومن "Deploy from a branch"
   اختر الفرع `main` والمجلد `/ (root)` ثم **Save**. انتظر دقيقة أو اثنتين.
5. ستظهر لك نسخة الموقع: `https://<اسمك>.github.io/rj100/`

## خطوات التثبيت على الآيفون (تفعلها مرة واحدة)
1. في **Safari** افتح الرابط من الخطوة 5.
2. استخدم التطبيق بشكل طبيعي أثناء اتصالك بالإنترنت (يفتح أول مرة).
3. من زر **مشاركة** (مربع السهم) اضغط **إضافة إلى الشاشة الرئيسية**
   (Add to Home Screen) ← **إضافة**.
4. الآن ستجد أيقونة **RJ100 Toolkit** على شاشتك الرئيسية — افتحها
   **في أي وقت ودون أي إنترنت**: تعمل 100% من ذاكرة الجهاز.

## ملاحظات
- كل الملفات هنا مكتفية ذاتياً: `index.html` فيه التطبيق كاملاً
  (التصميم + البيانات + الأيقونات + الشعار) بلا أي ملف خارجي أو CDN.
- لتحديث التطبيق مستقبلاً: غيّر رقم `CACHE` في `sw.js` إلى `rj100-v2`
  ثم أعد رفع الملفات — المتصفح سيحدّث النسخة تلقائياً.
- لو حصلت على خطأ في التثبيت: تأكد أنك تفتح عبر **https** وليس http.
